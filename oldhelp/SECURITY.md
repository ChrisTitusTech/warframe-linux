# Security Policy

## Reporting

Please report suspected security vulnerabilities through GitHub Private Vulnerability Reporting.

Do not open public issues for potential security problems.

## Scope

Examples of security issues:

- unintended transmission of sensitive local data
- arbitrary code execution
- privilege escalation
- compromised release artifacts or dependencies

The following are not considered security vulnerabilities by themselves:

- documented game-account or Terms-of-Service risk from the optional memory-scan feature
- general functionality bugs without a security impact

## Supported Versions

Security fixes are best-effort for:

- the latest release
- the current `main` branch

## Response

Initial triage is best-effort.
