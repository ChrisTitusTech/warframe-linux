# Security

The new application is not implemented; no supported release currently exists.
For a vulnerability, use the repository's private vulnerability reporting form
in the GitHub Security tab. Do not post credentials, raw inventory, memory dumps,
or credential-bearing URLs in public issues. If the private form is unavailable,
request a private contact route without including sensitive details.

The proposed experimental inventory provider handles game session material and
requires a separate review before release. See
[architecture](docs/ARCHITECTURE.md) for its data boundaries.
